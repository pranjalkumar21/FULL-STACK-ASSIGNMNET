# Full Stack Development Lab Assignment

This folder contains all 13 practicals as separate projects. Open each folder and follow its README.

## Quick guide
- Practicals 1–7: Open the `.html` file in a browser.
- Practicals 8–10: Run `npm install`, then `npm start` inside that practical's folder.
- Practical 11: Start MongoDB, add your connection string to `.env`, then run `npm install` and `npm start`.
- Practical 12: Demo e-commerce application. It uses a simulated checkout, not a real payment gateway. A real gateway requires merchant credentials and server-side verification.
- Practical 13: Run `npm install` and `npm run dev` inside `practical-13-react-portfolio`.

## Suggested GitHub upload
Upload the contents of this folder to your repository. Keep the practical folder names unchanged so each practical stays organized.
